✦ QuizQuest

A fun, interactive and responsive Quiz Game Application built with HTML, CSS, and JavaScript. QuizQuest lets users test their knowledge through different types of questions and instantly see how well they performed.

🚀 Features

🎯 Single Choice — Pick the one correct answer

☑️ Multiple Choice — Select all correct answers

✍️ Fill in the Blank — Type your answer

📊 Live Progress Bar — Track your quiz progress

✅ Instant Feedback — Know whether your answer is correct

🏆 Final Score — Get your score at the end

🔄 Play Again — Restart the quiz anytime

📱 Responsive Design — Works smoothly across devices

✨ Modern UI — Clean dark interface with gradients and animations


🛠️ Built With

HTML5 — Structure

CSS3 — Styling, animations & responsive layout

JavaScript — Quiz logic, validation & score calculation


🎮 How It Works

1. Start the quiz.


2. Read each question carefully.


3. Select or enter your answer.


4. Get instant feedback.


5. Move through all the questions.


6. Check your final score.


7. Try again and beat your previous score! 🔥
